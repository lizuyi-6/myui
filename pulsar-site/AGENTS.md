# PULSAR 官网取用规则

- 本目录是独立官网；原组件库与原试验场位于兄弟目录。
- 品牌设计先读 `../DESIGN-PREFERENCES.md` 的 R7 标识偏好：用户明确喜欢奶油白、深绿粗体 PULSAR、左侧星芒和小号 UI 角标。默认沿用这组构成和比例；此偏好不限制组件库的多风格覆盖，新的用户要求优先。
- 先读 `REUSE-MANIFEST.json`、`src/data/catalog.json` 和所选 `public/source/*.json`，优先利用已有组件。
- `src/vendor` 为逐字节副本，不在这里改组件实现；如需新增能力，先在组件库实现，再运行 `npm run sync`。
- 原创组件的 CSS 版要配套复制 CSS，其他接口与依赖以实际源码为准。
- 新页面保持清楚的地址、导航、真实文案、触摸和键盘路径。不要把尚无预览的源码条目标记为 LIVE。
- 持续装饰动效遵循暂停和系统减少动态。主题切换不清空会话便笺与点击状态。
- 检查读取具体数据字段，不只看构建、HTTP 200 或截图。记录失败与未覆盖路径，证据写入 `SITE-EVIDENCE.md`；工作账本追加 `WORKLOG.md`。
- 保留原库许可与作者信息。本目录默认本地演示，不以目录存在推断公开分发许可。
